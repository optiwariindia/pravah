# MVP1 Release Checklist

## Build

- [ ] Go tests and race checks pass.
- [ ] MongoDB integration test passes.
- [ ] SDK tests and export checks pass.
- [ ] `npm pack --dry-run` contains only runtime files.
- [ ] Quickstart delivers an SSE signal.
- [ ] Load target passes with 100 clients and 50 publications/second.
- [ ] Image health check becomes healthy and graceful shutdown succeeds.

## Security

- [ ] `SUBSCRIPTION_JWT_SECRET` and `ADMIN_API_KEY` are generated by the
      secret manager and are not committed.
- [ ] `COOKIE_SECURE=true`, production SameSite policy, and CORS origins are set.
- [ ] TLS terminates in the reverse proxy and SSE buffering is disabled.
- [ ] Production dependency audits are reviewed.

## Release artifacts

- [ ] Tag the Git revision.
- [ ] Build and scan the scratch image.
- [ ] Publish the versioned image and digest.
- [ ] Publish `pravah-sdk` to npm.
- [ ] Update `CHANGELOG.md`.
- [ ] Publish OpenAPI, quickstart, benchmark, and known-limitations links.

## Rollback

- [ ] Verify MongoDB backup.
- [ ] Confirm the previous image tag remains available.
- [ ] Confirm token-secret compatibility for the rollback window.
- [ ] Do not downgrade MongoDB across major feature compatibility versions.
