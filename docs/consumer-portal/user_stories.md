# 📝 User Stories - BizBandhan Pravah Website

## 1. Visitor & Public Onboarding
- **US-1 (Landing):** As a **Visitor**, I want to see a real-time signal visualizer so that I can understand the "flow" concept instantly.
- **US-2 (Registration):** As a **New Customer**, I want to register with my organization details (size, location, business type) so that the BizBandhan Pravah team can provide me with tailored support.
- **US-3 (Pricing):** As a **CTO**, I want to see the available plans on the pricing page, even if automated billing is not yet active, so I can budget for future usage.

## 2. Dynamic Policies
- **US-4 (Policies):** As an **Administrator**, I want to create and edit policy content (Privacy, Terms) via a secure interface so that I don't have to redeploy code for legal updates.
- **US-5 (Dynamic Serving):** As a **User**, I want to read the most up-to-date Privacy Policy at `/privacy-policy` so that I am informed about data handling.

## 3. Application Management
- **US-6 (App List):** As a **Customer**, I want to view all my registered Publisher and Subscriber applications in one place.
- **US-7 (API Keys):** As a **Developer**, I want to generate and copy API keys for my applications so that I can start using the SDK.
- **US-8 (Rotation):** As a **Security Manager**, I want to rotate an application's API key if I suspect it has been exposed.

## 4. Organizational Hierarchy
- **US-9 (Team Lead):** As the **Primary Account Holder**, I want to manage other users from my organization within the portal.

## 5. Future Scope (SaaS Scaling)
- **US-10 (Auto-Billing):** As a **Customer**, I want to automate my payments via Stripe (Future Scope).
- **US-11 (Invoices):** As a **Business User**, I want to manage my billing cycle and view past invoices (Future Scope).
