Why Pravah?

Designed to solve the biggest pain points of standard SSE and WebSockets.

Tab Synchronization

Standard SSE opens a connection for every tab. Pravah uses Leader Election via BroadcastChannel to ensure only one connection exists across all tabs, reducing server load by up to 90%.

Signal-Only Security

Never leak sensitive data. Pravah enforces a Signal-Only policy—sending only event names and resource IDs. The client then fetches data via your secure, authenticated REST APIs.

Dual-Core Engine

Choose your flavor. A lightweight Node.js implementation for rapid prototyping, or a high-concurrency Go engine for massive scale.

Quick Start

Launch BizBandhan instantly using Docker. No source code required.

Run the high-performance Go engine directly:

docker run -d -p 3000:3000 --name bizbandhan \
  -e MONGODB=mongodb://your-mongo-ip/pravah \
  optiwariindia/pravah-go:1.0.0

Create a docker-compose.yml and run docker-compose up -d:

services:
  bizbandhan:
    image: optiwariindia/pravah-go:1.0.0
    restart: unless-stopped
    ports:
      - "3000:3000" # Publish port for external access
    environment:
      - PORT=3000
      - MONGODB=mongodb://db/pravah
    depends_on:
      - db

  db:
    image: mongo:latest
    restart: unless-stopped
    volumes:
      - ./db-data:/data/db

💡 Pro Tip: Port Publishing
By default, our images use port 3000. If you are deploying behind a reverse proxy (like Nginx), you can skip port publishing and use internal Docker networking. For direct access, use -p 3000:3000.

Unified SDK

A single SDK for Vanilla JS and React with built-in Leader Election.

import Pravah from 'pravah-sdk';

const pravah = new Pravah({
  baseUrl: '/pravah',
  streams: ['global']
});

pravah.on('bid-updated', (signal) => {
  console.log('Update received for ID:', signal.id);
});
import { PravahProvider, usePravahListener } from 'pravah-sdk';

// Wrap your app once

  


// Use anywhere
const MyComponent = () => {
  usePravahListener(null, 'order-placed', (signal) => {
    alert(`New order: ${signal.id}`);
  });
  return <div>Dashboard</div>;
};

Proxy Configuration

Optimized for SSE with zero-buffering.

location /pravah {
    proxy_pass http://localhost:3000/pravah;
    proxy_set_header Connection '';
    proxy_http_version 1.1;
    chunked_transfer_encoding off;
    proxy_buffering off;
    proxy_cache off;
}
yourdomain.com {
    reverse_proxy /pravah/* localhost:3000 {
        flush_interval -1
    }
}
