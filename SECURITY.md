# Security Policy

## Supported Versions

Only the latest released major version of Pravah receives security fixes.

## Reporting a Vulnerability

Do not open a public issue for a suspected vulnerability. Email the maintainer
listed in `README.md` with:

- affected Pravah version and commit;
- deployment context and reproduction steps;
- expected and actual behavior;
- impact assessment, if known;
- any proof-of-concept payload that is safe to disclose privately.

Please avoid including real production API keys, signed subscription tokens,
personal data, or tenant payloads.

The maintainer will acknowledge valid reports and coordinate a private fix and
release. Public disclosure should happen only after an affected release has been
available long enough for operators to upgrade.
