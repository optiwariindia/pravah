# Contributing to Pravah 🌊

First off, thank you for considering contributing to Pravah! It's people like you that make Pravah a great tool.

## 🤝 How Can I Contribute?

### Reporting Bugs
- Use the **Bug Report** template.
- Describe the bug and provide steps to reproduce.

### Suggesting Enhancements
- Use the **Feature Request** template.
- Explain the "Why" and "How" of your suggestion.

### Pull Requests
1. Fork the repo and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. If you've changed APIs, update the documentation.
4. Ensure the test suite passes.
5. Make sure your code follows the existing style and conventions.

## 🏗️ Development Setup (Go Version)
1. Ensure you have Go 1.25+ installed.
2. Clone the repo and navigate to `pravah-go/`.
3. Run `go mod download`.
4. Start a MongoDB instance (or use the provided `docker-compose.yml`).
5. Run the server: `go run cmd/server/main.go`.

## 🛡️ Security
If you find a security vulnerability, please do NOT open an issue. Instead, contact the lead engineer directly at the email provided in the README.
